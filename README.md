# Nova
Ai assistant

## Mini JARVIS (local)

Run examples:

```bash
python3 -m jarvis --message "ls ."
python3 -m jarvis --message "read README.md"
python3 -m jarvis --message "https://example.com"
python3 -m jarvis --allow-system --message "run echo hello"

# REPL mode
python3 -m jarvis --repl
```
